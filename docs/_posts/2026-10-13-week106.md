E5 se entrenó con FastViT-SA12 preentrenado, usando imágenes RGB de 800×600. Se recortaron los primeros 140 píxeles de la parte superior, luego la imagen se llevó a 256×256 y se escaló dividiendo entre 255.

El modelo solo predice steer. El throttle no entra al modelo ni se predice; únicamente se usó para balancear mejor los datos durante el entrenamiento con 20 combinaciones de steer y throttle.


En las pruebas con BehaviorMetrics, E5 funciona mejor cuando se usa un throttle fijo de 0.45. Con ese valor el comportamiento es más estable y logra avanzar mejor por el circuito. Al cambiar el throttle, el modelo empieza a tener problemas en algunas curvas e incluso puede perder estabilidad en tramos rectos.

Parece que este modelo aprendió bien el steer, pero quedó muy amarrado a un rango específico de velocidad. Como solo funciona bien con throttle=0.45, para el próximo entrenamiento conviene darle al modelo información de velocidad o throttle durante la inferencia, para que pueda ajustar mejor el giro según cómo se esté moviendo el vehículo.
