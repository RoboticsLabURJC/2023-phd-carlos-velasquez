## Nuevo dataset RGB

El nuevo dataset amplía el conjunto anterior de **60.000 muestras** a **120.367 imágenes RGB válidas**, recolectadas en **Town01, Town03, Town04, Town05, Town06 y Town07**.

Se mejoró principalmente el **etiquetado y la trazabilidad de las muestras**. Cada imagen puede identificarse por **Town, run y tipo de segmento**, diferenciando entre **curvas, rectas, difficult y full_route**. Además, se verificó la correspondencia entre las imágenes y sus registros.

Esta estructura permite realizar un **split de entrenamiento y validación más controlado**, evitando que muestras altamente correlacionadas pertenecientes al mismo run aparezcan simultáneamente en *train* y *validation*. Esto permite obtener evaluaciones offline más representativas.

### Distribución de las 20 clases

Para analizar conjuntamente las etiquetas de dirección y aceleración se utilizaron **20 clases**, obtenidas mediante la combinación de **5 intervalos de `steer` × 4 intervalos de `throttle`**.
